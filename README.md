# Pi Plugins

A workspace for Pi extensions.

## Packages

- `@jingoz/pi-questionnaire`: TUI questionnaire tool. See [packages/questionnaire](packages/questionnaire/README.md).
- `@pi-plugins/image-input`: Pi 0.84.3+ TUI clipboard bridge for idle PNG/JPEG/WebP submissions. It keeps native editor paths visible until submit, replaces converted occurrences with `[Image]`, fails closed with draft restoration, and leaves non-TUI input unchanged. See [packages/image-input](packages/image-input/README.md).
