# 领域文档

工程 skills 探索代码库时，应按以下规则读取本仓库的领域文档。

## 探索前读取

- 仓库根目录的 **`CONTEXT.md`**。
- **`docs/adr/`** 中与待处理区域有关的 ADR。

如果这些文件不存在，**静默继续**。`/domain-modeling` skill 会在领域术语或决策真正明确后按需创建它们。

## 文件结构

单上下文仓库：

```
/
|-- CONTEXT.md
|-- docs/adr/
`-- packages/
```

## 使用术语表中的词汇

使用 `CONTEXT.md` 中定义的领域术语。如果缺少所需概念，应重新考虑该用词，或记录此缺口并交由 `/domain-modeling` 处理。

## 标记 ADR 冲突

如果输出与现有 ADR 冲突，应明确指出，不得静默覆盖。
