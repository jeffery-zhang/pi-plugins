# 01 — 单张 Staged Image 端到端交付

**What to build:** 交付最小但完整的 TUI 图片输入路径：用户粘贴一张图片后，在 Image Draft 中看到 `[Image #1]`；提交时该 Staged Image 在入口完成校验和规范化，作为同一条用户消息的 Image Attachment 进入模型上下文和会话历史，临时路径不对用户、模型或历史暴露。

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] 插件以仓库标准私有 ESM 包形式加载，并声明可运行的检查和测试命令。
- [ ] Pi 原生剪贴板流程插入的单张规范临时图片路径会在编辑器中替换为 `[Image #1]`。
- [ ] 插件不自行实现平台剪贴板读取，并保留默认编辑器的快捷键、历史、自动补全和提交行为。
- [ ] 提交交互输入时，已知的 `[Image #1]` 被解析为一个经过 Pi 公开能力规范化的 Image Attachment。
- [ ] 提交文本和持久化用户消息保留 `[Image #1]`，但不包含原始临时路径。
- [ ] 普通文本、任意文件路径和未知 Image Reference 保持原样。
- [ ] 自动场景测试从编辑器路径插入覆盖到提交后的文本和图片结果，不直接断言内部映射实现。
- [ ] 使用真实 TUI 加载方式完成单图粘贴与提交冒烟验证。
