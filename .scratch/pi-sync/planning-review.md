## 已确认的测试入口

以 Pi 已注册的首次连接、Save、Restore 命令作为唯一产品测试入口。使用临时 Agent Environment、真实本地 bare Git 仓库和最小包 fixture，观察文件、快照、备份、Git 历史和用户提示；只在外部 I/O 边缘注入失败。真实 Pi 宿主冒烟也使用这组命令，不新增测试专用同步接口。

完整内容见 [正式规格](spec.md)。

## 阻塞关系的理由

- 01 提供可用的命令和仓库连接，02 才能完成真实 Save；03 使用 02 产出的快照完成 Restore。
- 04、05、06 都扩展已可运行的 Save/Restore 路径；它们各自只依赖 03，不相互制造阻塞。
- 07 验证完整内容和中断行为，需要 04、05、06 全部完成；不再重复列出传递依赖。
- 当前没有需要提前交付的宽重构；没有单独的“只建 schema”“只建 Git 层”“最后补测试/错误提示”横向任务。
