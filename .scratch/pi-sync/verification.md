## 已执行的命令与测试入口

- Windows 执行包级 check、test 和 smoke。
- Linux 在隔离运行时执行相同包的 check 和 test。
- 实际 Pi CLI 使用临时 package 加载入口，关闭自动扩展、Skills、MCP 和在线模型发现，使用隔离 Agent Directory。
- 真实 TUI 仅信任测试目录的当前会话，没有把临时目录或其父目录添加为用户的持久信任范围。
- Node 测试从注册的用户命令进入；真实宿主检查使用相同命令，没有新建测试专用同步接口。

## 关键覆盖

1. 空仓库首次保存、无快照还原错误、已存在历史上的新快照保存。
2. 供应商、模型、设置往返；源机器本机字段不导出，目标机器本机字段保留。
3. 已知敏感字段过滤、纯环境变量引用保留、独立凭据和环境文件不导出；不扫描其他文本。
4. Provider 或包名称恰为 token/env 等时不被误当成鉴权字段；秘密值可以是对象，已知字段仍过滤。
5. 本地扩展、角色、提示词、自定义配置、JSON 数组资源往返；pi-fff 本机数据库路径保留。
6. npm 未固定声明保存为实际直接版本；Git 来源保存为实际 commit；资源启用筛选保留。
7. 实际调用 Pi 安装固定 npm/Git fixture，目标环境重启后能执行 npm、Git 和本地依赖扩展的命令。
8. Git 安装生成的未跟踪锁文件作为安装产物处理，真实未提交源码修改阻止保存。
9. 备份失败、应用中断、回退失败、中断日志恢复；没有 Git 时仍可执行本地 recover。
10. 受管范围外内容、独立鉴权、已有环境文件保留；删除的定义与旧附带值存在本地备份。
11. 两客户端保存竞争、三次重试上限、丢失推送回执后查询、无法查询时结果未知。
12. 操作重入、过期与活跃锁、取消、会话结束；实际进程树超时后后代不会延迟写入。
13. 非法路径、越界链接、资源校验失败、格式/版本错误、无效 JSON 与非 UTF-8 输入均不部分应用，不回显配置正文。
14. 命令或运行时缺失、Node 版本不满足、仓库访问不确定性、包版本、认证、网络和磁盘空间错误的提示及状态。
15. Windows PowerShell shim 的参数保持为数据；裸批处理无安全 shim 时拒绝，引号、百分号和命令元字符不会被重新执行。
16. 分块中文输出完整，已知 URL 凭据和已知字段值被诊断过滤。
17. print/JSON/RPC 和 TUI 模式守卫、参数错误、用户自行重启与待鉴权结果；TUI 错误通过原生错误呈现一次。

权限、网络、磁盘或回退失败使用外部 I/O 边缘故障注入验证；实际 Git 提交/推送/HTTP 拉取、包安装、文件替换和 Pi 宿主均真实运行。没有使用生产仓库来验证拒绝权限或故障。

## 下载与隔离

- 开发依赖使用 registry.npmmirror.com，优先复用既有缓存。
- Linux Node 压缩包从国内镜像下载，并与 Node 官方 SHASUMS256.txt 校验一致后执行。
- Linux 包依赖从国内镜像安装在 WSL 用户缓存中的独立测试运行时；没有替换系统 Node 或用户 Pi。
- 测试扩展由本地 registry、Git HTTP fixture 和最小 peer 元数据提供；未请求真实模型或使用生产 API Key。
- Git 作者、Git 全局配置、npm 用户配置和测试 Home 均隔离；单独的凭据文件不由同步逻辑读取。
- 测试未对用户的实际 Agent Directory 执行保存或还原；没有全局安装本插件、发布 npm 包、提交或推送本项目仓库。

## 限制与恢复边界

- macOS 尚未实测；Linux Bun 安装路径没有额外执行，Linux验证采用 Node/npm。
- 只过滤已知字段，未知位置中的秘密仍可能随资源上传；供应商改地址后可能继续使用本机 Key。
- 直接版本/commit 固定不保证传递依赖、系统程序和扩展自身的跨平台兼容性。
- 安装脚本在受管范围外造成的副作用不保证回滚；本机备份不会自动清理，需要预留空间。
- 还原时应让其他会写同一 Agent Directory 的进程保持空闲；同步互斥不能约束不遵守该锁的外部写入者。
- 用户旧仓库已有的文件和历史不由 Pi Sync 自动清理。
