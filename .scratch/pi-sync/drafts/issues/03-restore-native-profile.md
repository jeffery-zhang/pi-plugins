# 03: 备份并强制还原原生配置

**What to build:** 用户在另一份 Agent Environment 执行 Restore，将远端原生配置强制还原到 Managed Scope，在替换前获得可定位的 Restore Backup；还原失败能回退，成功后知道需要自行鉴权与重启。

**Blocked by:** 02: 保存供应商、模型与通用设置快照。

**Review:** approved-and-published (historical draft)

- [ ] 拉取并完整验证所选远端快照，区分仓库无提交、没有快照、版本不存在、格式不支持和内容无效；非法内容不产生部分应用。
- [ ] 验证受管根和所有待写入目标，拒绝绝对位置、父级逃逸或越界链接；不修改项目或受管范围外内容。
- [ ] 按快照替换受管字段、移除目标机多余的受管定义，保留非受管设置与本机鉴权；供应商地址或协议改变直接应用，不逐项确认。
- [ ] 覆盖前备份旧受管配置，备份包括原始附带值，仅保存在本机；独立凭据文件不读取不改写，删除定义前仍能从备份找回其旧内容。
- [ ] 备份创建或写入条件失败时不开始覆盖；应用中途失败回退受管文件和声明，成功回退及回退失败都报告实际影响和真实备份位置。
- [ ] 相同工作副本的写操作不能交叠；操作开始前的取消和超时停止应用，避免后续追加任务前留下无保护的并发写入。
- [ ] 缺少 Key 标为待鉴权，不把已恢复但不可推理的模型报告为配置损坏；必要的占位 Key 由用户自行补充。
- [ ] 完成磁盘还原后报告已还原、待重启，不自动退出 Pi，不立即加载新扩展，不以热重载承诺完全生效。
- [ ] 从命令入口完成“源环境 Save → 有额外配置的目标环境 Restore”，验证受管一致、范围外不变、本机鉴权保留与备份可恢复。
- [ ] 故障注入验证快照无效、备份失败、写入中断、回退失败和未鉴权路径；检查实际文件与提示一致，不仅断言内部错误抛出。
- [ ] 在真实 Pi 临时环境触发 Restore，记录待重启及下一次启动读取到新原生配置的证据，运行包级检查与测试。
