# 05: 保存和还原本地用户资源

**What to build:** 用户能够把包清单之外的本地扩展及配套角色、提示词、Skills、主题、快捷键和全局指令一起保存，并在目标环境恢复；显式选入的扩展自定义内容也随快照还原。

**Blocked by:** 03: 备份并强制还原原生配置。

**Status:** resolved

- [x] 通过必要的选择或声明纳入 Agent Directory 内本地用户资源及扩展自定义文件，保存选定内容；范围外引用明确报告未覆盖，不自动打包项目或其他用户目录。
- [x] 本地扩展能携带配套角色文本、依赖声明和已有锁定信息；目标机按自身安装方式准备依赖，缺少必需输入或准备失败时明确阻止不完整还原。
- [x] 本机 Subagent 与其用户角色可作为一个完整场景往返保存还原，提示词、Skills、主题、快捷键和全局指令的内容及原生发现语义得到保留。
- [x] 扩展自定义配置只对明确支持的可移植字段生效，本机路径与运行历史不误导出；支持纳入自定义资源，不建立通用插件适配框架。
- [x] 仅过滤已知敏感文件或结构化字段，其他源码、Markdown 和未知内容原样处理，不增加秘密扫描、审核确认或任意字符串脱敏。
- [x] 排除安装产物、依赖树、平台工具、会话、历史、缓存及 Pi Sync 自身工作内容；资源不能递归收集备份或工作副本。
- [x] 处理三系统路径和大小写等差异，任何资源或链接导致读写越出受管根时明确拒绝；不写入用户任意外部位置。
- [x] Restore 在受管资源范围内强制更新和移除多余项，先备份再应用；独立本机内容保留，资源写入失败时与原生配置一并按已有回退合同处理。
- [x] 从同一命令入口验证本地扩展与角色配套、显式自定义内容、删除后可从备份找回、外部引用报告以及不收集自身工作内容。
- [x] 覆盖越界、链接、不可读资源、依赖准备和应用失败，验证没有越界改动且错误提示说明实际阶段和状态。
- [x] 在实际宿主的下一次启动验证资源被正确发现与加载，运行包级检查和测试，更新可恢复内容清单及能力边界。
