# Pi Purge

Pi Purge 通过自带的内置提示词调整模型在用户指定内容场景中的指令执行表现，同时保留 Pi 作为编程代理的能力。DS 是首版必验模型。

## Language

**目标场景**：
用户用于检验模型是否执行指定内容指令的对话场景；当前包括角色扮演。
_Avoid_：未说明预期行为的“敏感内容测试”

**行为生效**：
模型在目标场景中实际执行用户指令的表现。提示词已经送达不等于行为已经生效。
_Avoid_：用“注入成功”代指行为已经生效

**必验模型**：
必须完成行为生效验证的模型；该要求不限制其他模型使用。
_Avoid_：唯一支持的模型、模型白名单


**内置提示词**：
Pi Purge 自带、无需使用者另行提供的指令正文。
_Avoid_：DSH 配置、外部提示来源
