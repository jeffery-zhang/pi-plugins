# Pi Sync

Pi Sync 让用户在多台机器之间保存和还原可移植的 Pi 环境。每台机器的鉴权由用户自行管理。

## Language

**Agent Environment（Agent 环境）**:
用户级的供应商定义、模型定义、扩展与设置构成的 Pi 工作环境。项目专属环境与用户的鉴权信息不属于这里的可移植环境。
_Avoid_: 整机环境、登录状态

**Environment Snapshot（环境快照）**:
某次保存所记录的可移植 Agent 环境。它表达要还原的配置与资源，鉴权由目标机器自行管理。
_Avoid_: 全目录备份、凭据备份

**Managed Scope（受管范围）**:
环境快照负责保存和还原的配置与用户资源集合。目标机器的鉴权与明确保留的本机专属内容不属于该集合。
_Avoid_: 整个用户目录、所有有效配置

**Save（保存）**:
以当前机器的 Agent 环境创建并发布新的环境快照，既有快照仍可追溯。
_Avoid_: 双向合并、还原

**Restore（还原）**:
以远端环境快照重建目标机器的受管状态，替换前保留旧状态的本地备份。
_Avoid_: 仅增量安装、保存

**Restore Backup（还原备份）**:
还原前目标机器受管内容的本地副本，用于失败回退或找回旧状态。
_Avoid_: 远端环境快照、凭据同步
