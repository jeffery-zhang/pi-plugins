# Model Detect

Model Detect 用目录元数据补全用户已有模型的能力、限制和价格。

## Language

**目标模型（Target Model）**：
用户在 Pi 中已有、希望更新元数据的模型。其服务提供方和模型标识共同确定更新对象。

**目录条目（Catalog Entry）**：
models.dev 中一个服务提供方名下的模型记录。同一个基础模型经不同服务提供方提供时，对应不同目录条目。
_Avoid_: 把目录条目简称为基础模型

**目录元数据（Catalog Metadata）**：
目录条目声明的模型能力、使用限制和价格。它描述目录中的已知信息，不构成对目标模型服务的实际探测结果。
_Avoid_: 实测参数、实际账单

**来源映射（Source Mapping）**：
目标模型与一个明确目录条目之间由用户指定的对应关系。它允许本地模型名称或标识与目录模型不同，而不改变目标模型的身份。

**原厂目录价（Vendor Catalog Price）**：
模型原厂的目录条目公布的标价。它是目标模型成本估算的价格依据，不表示代理或网关的实际账单。
_Avoid_: 代理实际收费
